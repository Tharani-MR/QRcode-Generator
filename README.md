# QR Code Generator

A simple React application that generates a QR code from a URL entered by the user.  
Users can preview the generated QR code and download it as an image.

## 🚀 Features

- Generate QR code from any URL
- Input validation with error message
- Loading indicator while generating QR
- QR code preview
- Download QR code as PNG
- Responsive UI

## 🛠️ Built With

- React
- Vite
- JavaScript
- CSS
- qrcode npm package
